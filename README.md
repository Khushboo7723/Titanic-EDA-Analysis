Titanic Dataset – Exploratory Data Analysis (EDA)

Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the Titanic passenger dataset using Python. The objective is to understand passenger demographics, identify survival patterns, handle missing data, and discover meaningful insights through data analysis and visualization.

Objectives

- Understand and explore the Titanic dataset.
- Identify and handle missing values and duplicate records.
- Perform statistical analysis.
- Analyse survival rates based on different passenger characteristics.
- Visualize patterns and relationships between features.
- Generate meaningful insights using Pandas.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Dataset Information

The dataset contains information about 891 passengers and 12 columns, including:

- PassengerId
- Survived
- Pclass
- Name
- Sex
- Age
- SibSp
- Parch
- Ticket
- Fare
- Cabin
- Embarked

Analysis Performed

1. Data Understanding

- Dataset loading and inspection.
- Checking data types and statistical summaries.
- Identifying missing values and duplicates.

2. Data Cleaning

- Handling missing values.
- Removing duplicate records.
- Preparing data for analysis.

3. Exploratory Data Analysis

- Gender distribution.
- Passenger class distribution.
- Age and Fare distribution.
- Survival distribution.

4. Grouping and Aggregation

- Gender-wise survival rate.
- Passenger class-wise survival rate.
- Average age by passenger class.
- Average fare by passenger class.
- Survival analysis by embarkation location.

5. Data Visualization

- Histograms
- Count plots
- Box plots
- Correlation heatmap

Key Findings

- Female passengers had a higher survival rate than male passengers.
- First-class passengers had a higher survival rate than second- and third-class passengers.
- Third-class passengers had the lowest survival rate.
- Passenger gender and class showed strong associations with survival outcomes.

Conclusion

This project helped explore the Titanic dataset and understand the factors associated with passenger survival. It strengthened practical knowledge of Python, Pandas, data cleaning, aggregation, and data visualization.
